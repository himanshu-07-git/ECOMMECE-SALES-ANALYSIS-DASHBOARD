# ECOMMECE-SALES-ANALYSIS-DASHBOARD
📊 Ecommerce Sales Analysis Dashboard
📌 Project Overview

This project presents an interactive Ecommerce Sales Analysis Dashboard designed to track key business metrics such as sales, profit, quantity, and order volume. It helps in understanding sales performance, customer behavior, and category-wise trends for better decision-making.

🎯 Objectives
Monitor overall sales and profit performance
Analyze category-wise and region-wise sales trends
Identify top-performing products and categories
Track year-over-year (YoY) growth
Enable data-driven business insights

🔹 Filters Available
Year (2011–2014)
Region (Central, East, South, West)
Segment (Consumer, Corporate, Home Office)
